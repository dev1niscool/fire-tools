Find your model and version

In Settings → Device Options, open About Fire Tablet for the generation and System Updates for the installed Fire OS version. Look up that build’s feature limits. After USB setup, the Connection tab also shows your Android API level (SDK), supported processor architectures (ABIs) and active user.

Check your API level and architecture

Tablet changes require authorized ADB, Amazon as the reported manufacturer, a model name, API 23 or newer, and the primary adult profile (User 0). Firmware may still refuse individual changes.

The 2023 HD 10 reference Play services APK requires API 30 and arm64-v8a. For Fire OS 6 or 7, choose standalone APKs compatible with your tablet’s ABI and a minimum API at or below its installed level. Choose Google Play files.

Fire Tools verified signatures and install order on a computer for four v46 core APKs and two separate sync adapters. ADB installation was simulated. Installation, sign-in and ad visibility on physical tablets remain unverified. Project test record.
