Try the connection first

On Windows 10 or 11, you need a separate driver download only if Windows hasn’t set up the tablet’s ADB interface. Fire Tools uses the copy of Google’s Android Debug Bridge (ADB) you select. It ships no USB driver and has no driver installer. Google Platform-Tools · Windows driver updates

  1. Unlock the tablet, enable USB debugging, and connect with a data-capable cable. Give Windows time to finish device setup. Enable USB debugging
  2. In Fire Tools, choose Connection → ADB → Browse and select platform-tools/adb.exe. Choose Scan devices.
  3. If the state is device, select the tablet and choose Use selected tablet. Driver setup is complete.

Read the scan result

unauthorized
ADB already sees the tablet. Unlock it and approve the USB debugging prompt for your computer. Choose “Always allow” only on a computer you trust, then scan again.
offline
Disconnect and reconnect the tablet, check the debugging prompt and scan again. Try another cable or USB port if the state persists.
File Explorer sees the tablet, but the scan is empty
File Explorer uses MTP for file transfers. ADB has its own USB interface. Confirm USB debugging is on, then look for Android Composite ADB Interface in Windows Device Manager. A Fire entry with a yellow warning under Other devices can indicate a missing ADB driver.

How Windows checks a driver catalog

Use the driver files with Windows Device Manager
  1. Download the ZIP using the link in Amazon’s guide and compare its hash. Extract the ZIP. Using a trusted archive utility such as 7-Zip, open Fire_Devices ADB drivers.exe as an archive and extract its contents to a folder. This reads the files without launching the unsigned installer.
  2. Keep android_winusb.inf, its .cat files and the architecture subfolders together. In Device Manager, select the Fire device needing its ADB driver. Choose Update driver → Browse my computer for drivers, select that folder and include subfolders.
  3. Let Windows enforce driver signing. If Windows rejects the signature or says the driver is incompatible, stop and use Windows Update or Amazon support. After a successful install, reconnect, authorize the tablet and scan in Fire Tools. Android’s OEM driver instructions
