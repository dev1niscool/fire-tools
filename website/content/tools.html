Find a tool

Select your tablet, then open Tools and search by name or category. Choose Read to inspect data or Review... to check an action before choosing Confirm and run.

Back up settings and files

  1. Backup and restore → Back up settings and package inventory saves selected settings and owner package states. Enter the full path to a new folder on your computer.
  2. Use Copy shared-storage folder for downloads or photos. Enter a folder such as /sdcard/Download and a new local destination.
  3. Use Restore supported configuration backup for settings and package states, or Files → Copy a file to the tablet for individual files.

Choose a home screen or keyboard

  • Launcher and input → Set an installed home launcher. Enter its Android component and leave the Fire launcher enabled while testing. Switch back with Restore Fire home launcher.
  • List installed input methods shows keyboard service names. Copy one into Select an installed keyboard and note the previous default in the preview to switch back later.

Change a setting and undo it

To shorten menus and transitions, follow the animation speed guide on the tablet or in Fire Tools.

Choose Settings → Read one setting before using Change or delete a setting. To undo, enter the same database and key in Restore a saved setting. Where to find undo files

Choose a Private DNS resolver

On Android 9 or newer, open Network → Configure private DNS. Choose a provider under DNS mode or provider, or choose hostname and enter your own DNS-over-TLS hostname. The preview shows the exact destination. The connection encrypts system DNS queries in transit, and the provider can see the domains requested.

  • Cloudflare offers an unfiltered resolver and a family option that filters malware and adult domains. Cloudflare resolver details
  • Quad9 filters known malicious domains. Quad9 resolver details
  • AdGuard filters advertising and tracking domains. Its family option also filters adult domains and enables Safe Search where supported. AdGuard resolver details
  • Mullvad Adblock filters advertising and tracking domains. Mullvad resolver details

To preview Quad9 from the command line, run python -m open_fire_toolkit tool private-dns --serial SERIAL --param mode=quad9. After applying a change, try opening a website on the tablet. To recover the settings saved before your first change, choose Network → Restore private DNS configuration.

Capture the screen or diagnose a problem

Unlock the tablet, then choose Screen and diagnostics → Save a screenshot (PNG) or Record the screen (silent MP4, 1–180 seconds). Protected video may appear blank.
