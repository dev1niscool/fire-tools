Use a personal APK bundle

Extract the personal Fire Tools ZIP. The google-apks folder beside the launchers contains the four Google Play files. Calendar and Contacts Sync are optional separate downloads.

  • Desktop · Open Google Play → Use bundled APKs → Verify and review.
  • Chrome · Open Browser tools and select the four files in the folder. You can save the verified set in this browser profile for your next visit.

The public source ZIP includes a builder for making a personal copy from the four downloads above. Google licenses these apps separately. Build a personal ZIP · Google Mobile Services licensing.

Verify the files and install

  1. Check the file hashes. Use Google Play → Choose APKs → Check scan records before connecting. A SHA-256 match identifies the exact scanned bytes.
  2. Check the signatures. Complete the USB and Android tools setup and choose Verify and review. Fire Tools checks package ID, API, ABI and Google’s pinned signer, including the verified key rotation for Play services.
  3. Read the plan. Check the model, serial and install order. For sync alone, select just the adapters. Fire Tools verifies the installed core packages.
  4. Choose Confirm and run. Fire Tools checks installed bytes for owner user 0. Failure stops the batch after any successful installs. After success, optionally restart via Connection → Review reboot, then sign in on the tablet.

Choose Google Play → Component status to see which packages are installed and enabled for the owner. If an updated component is still disabled, Fire Tools reports it. Open Play Store on the tablet to check sign-in.
