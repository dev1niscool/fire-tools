Start Fire Tools on your computer

  1. Download the 0.5.0 source ZIP. Extract it and open the folder containing the launchers. Download Fire Tools from GitHub · Release notes and checksum.
  2. Install Python 3.11+ with Tk. Select Tcl/Tk on Windows or install python3-tk on Debian/Ubuntu. Python downloads.
  3. Run a launcher from the extracted folder. The offline demo works without a tablet.

Select the Android tools

Extract Google’s Platform-Tools. In Connection → ADB → Browse, select platform-tools/adb.exe (Windows) or platform-tools/adb (Linux). Get SDK Platform-Tools.

For APK installation, install Android SDK Build-Tools under Tools → SDK Manager → SDK Tools in Android Studio. Set three more fields in Fire Tools. Using SDK Manager.

  • AAPT — aapt.exe or aapt in your Build-Tools version folder.
  • APK signer — lib/apksigner.jar in that folder.
  • Java — bin/java.exe or bin/java from a JDK. Android Studio includes Java in jbr/bin. The project tested Build-Tools 36.0.0 with JDK 21.

Authorize the USB connection

  1. Switch to the primary adult profile. In Settings → Device Options → About Fire Tablet, tap Serial Number seven times.
  2. Return to Device Options → Developer Options. Turn on Developer Options and USB debugging (sometimes Enable ADB). If Windows cannot see the ADB interface, check the USB driver guide and audit. Amazon’s Fire tablet USB and driver guide.
  3. Unlock the tablet and connect a USB data cable. Choose Connection → Scan devices, then approve your computer’s RSA fingerprint on the tablet.
  4. Scan again. Highlight your serial with state device and choose Use selected tablet. Note the model, Fire OS, SDK and ABIs.

Changes require owner user 0 and API 23 or newer. Original XDA guide · Archived XDA guide.

If the tablet does not appear

  • Unauthorized. Unlock, reconnect, accept the debugging prompt and scan again.
  • Offline or missing. Try another data cable or port. Check Windows Device Manager for Android Composite ADB Interface, or Linux USB permissions and udev rules. Android’s hardware device setup.

Afterward, Developer Options lets you turn off USB debugging and revoke saved authorizations.
