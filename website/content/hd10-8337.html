Check the tablet before connecting to Wi-Fi

This package is for the Fire HD 10 (2023, 13th generation), model KFTUWI. On a new tablet, choose the offline setup option if offered. If setup requires an online update, stop here. Amazon can download a newer build as soon as the tablet connects. Model specifications · Amazon’s current updates.

With Wi-Fi off, open Settings → Device Options. Check the generation under About Fire Tablet and the installed version under System Updates.

  • Earlier than 8.3.3.7 on this model? Back up important files and charge the tablet before continuing. Stop if another update is already queued to install.
  • Already on 8.3.3.7? Skip the download and go to future updates.
  • On 8.3.3.8 or newer, or using a different model? Stop here. This package rejects newer installed builds and other models. A factory reset cannot roll back Fire OS. Amazon’s downgrade guidance.

How to check the SHA-256

Open PowerShell or a terminal in the folder containing the downloaded file. Use the command for your computer.

Windows PowerShell

Get-FileHash -Algorithm SHA256 .\update-kindle-Fire_HD10_13th_Gen-RS8337_user_3186_0029461607044.bin

macOS

shasum -a 256 update-kindle-Fire_HD10_13th_Gen-RS8337_user_3186_0029461607044.bin

Linux

sha256sum update-kindle-Fire_HD10_13th_Gen-RS8337_user_3186_0029461607044.bin

Uppercase and lowercase letters in the digest are equivalent.

Install the local file over USB

  1. Keep the tablet offline. Connect it to your computer with a USB data cable. Unlock it, tap the USB charging notification and select Transfer files.
  2. On your computer, open Fire → Internal storage. Copy the verified .bin directly there, alongside folders such as Download. Wait for the copy to finish, then disconnect the cable.
  3. On the tablet, open Settings → Device Options → System Updates → Update. If it only offers an online check, reports a different version or rejects the package, stop. Let the tablet finish restarting, then check that System Updates shows 8.3.3.7.

The stock updater performs the installation. USB debugging is only needed for the Fire Tools controls below. We verified the full download’s SHA-256, update signature and target build. Physical installation remains untested. Amazon’s manual USB update instructions.

Before reconnecting to Wi-Fi

Fire Tools cannot guarantee that an online tablet will stay on 8.3.3.7. If keeping this version is essential, leave the tablet offline. An update downloaded earlier may still install.

  1. On the primary adult profile, enable USB debugging and select the tablet. In desktop Fire Tools, open System updates → Read updater states.
  2. Select the eligible enabled updater packages, choose Review disable… → Confirm and run, then read their states again. If Fire OS refuses or any updater stays enabled, treat automatic updates as active.

A disabled state confirms the change for those packages. Other update routes may remain available, and blocking updates can delay security patches. Restore the updater packages.
