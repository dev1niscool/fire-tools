Tablet connection

Disconnected

Enable USB debugging on the tablet, plug it into this computer with a data cable, then select it in Chrome.

USB setup and troubleshooting
  1. On the primary adult profile, open Settings → Device Options → About Fire Tablet. Tap Serial Number seven times.
  2. Return to Device Options → Developer Options and enable USB debugging (sometimes Enable ADB). Keep the tablet unlocked.
  3. Choose Connect tablet, pick your Fire in Chrome, then approve the USB debugging prompt on the tablet. Leave Always allow unchecked. Finish your work in this tab.

If Chrome cannot open the tablet, close other ADB tools and tabs, reconnect the cable, then try again. Windows may need an ADB driver and Linux may need USB permissions. USB driver guide.

Tablet tools

Install Google Play

Save the audited APK builds on your computer. For a new installation, choose Google Services Framework, Google Play services and Play Store together. Add Account Manager for the four-file setup. The browser checks exact file hashes locally. About the scan records.

You can check files before connecting. The reference Play services build requires Android 11 (API 30) or later and ARM64.

Personal APK pack

Choose the four APKs from your personal copy’s google-apks folder, or use the exact APKMirror builds linked above. Save them once in this Chrome profile (about 285 MiB). On your next visit, load the set and review installation. Chrome rechecks the files each time. Clearing site data removes the copy.
