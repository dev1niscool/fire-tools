Task 4 desktop GUI

Implemented
- Connection, Google Play, Lock-screen ads and Apps views use the shared service public API.
- Setup includes the four external tool paths, USB-debugging instructions and explicit selection
  from the scanned device list. The Connection view displays model, firmware, Android SDK,
  ABIs and active profile.
- Every device change runs after a modal plan review. The plan shows the tablet serial, service
  warnings, step details, and APK hashes and signers in install order when present.
- A single worker runs service calls using plain captured data. Tk schedules queue polling.
  Conflicting actions are disabled while busy or while a plan is open, and a rejected busy
  submission cannot run later.
- Demo mode selects DemoToolkit and offers fictional APK filenames for plan review. Mode
  banners, review controls and completion logs distinguish simulated activity.
- Browser navigation uses fixed vendor URLs on explicit clicks.
