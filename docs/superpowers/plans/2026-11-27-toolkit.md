# Open Fire Toolkit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Read your assigned task brief, not the whole implementation history.

**Goal:** Deliver an inspectable desktop/CLI toolkit for verified Google Play installation and reversible ad-setting experiments.
**Architecture:** A narrow ADB boundary, independent APK verification, immutable action plans and one service shared by GUI/CLI. Runtime is Python standard library; Android tools explicitly configured externally.
**Tech Stack:** Python 3.11+, tkinter/ttk, argparse, unittest; Google ADB/aapt/apksigner and Java for real hardware operations.
**Spec:** docs/superpowers/specs/2026-11-27-toolkit-design.md

## Global Constraints
No bundled binaries/APKs, original implementation copies, silent downloads/updates, telemetry, shell=True, firmware flashing, certificate installation or OTA blocking. Explicit serial, fail-closed verification, confirmed writes. Python 3.11+ standard-library runtime. Never claim absolute safety or real-device testing.

## Review Focus
Host/remote shell injection; switching device or APK after preview; partial installation; unauthorized/secondary-user tablet; misleading signature/firmware assurances.

## Interfaces (binding)
`adb.py` owns frozen dataclasses Device(serial:str,state:str,model:str='') and DeviceInfo(serial,model,manufacturer,fire_os,android_release,sdk:int,abis:tuple[str,...],user_id:int). AdbError(Exception). AdbClient(path) methods devices()->list[Device], info(serial)->DeviceInfo, shell(serial,args:Sequence[str],timeout=30)->str, install(serial,apk:Path)->str, packages(serial,disabled_only=False)->list[str], reboot(serial)->None. All device calls require validated serial and connected state. shell quotes remote tokens; callers supply tokens, never shell fragments. install requires 'Success' and rejects Failure even rc=0. info reads properties via getprop and current user; unknown sdk/user fails closed. Methods never select a first device.

`apk.py` owns ApkError(Exception), frozen ApkInfo(path:Path, package:str, version_code:int, version_name:str, min_sdk:int, abis:tuple[str,...], sha256:str, signer_sha256:tuple[str,...], split:bool=False), ApkVerifier(aapt_path,apksigner_jar,java_path), inspect(path)->ApkInfo. Helpers google_play_order(apks:Sequence[ApkInfo],sdk:int,abis:Sequence[str])->tuple[ApkInfo,...], file_sha256(path)->str. GOOGLE_SIGNER_SHA256 constant. Verify apksigner cryptographically (must succeed and explicitly emit 'Verifies'); inspect package via aapt; reject split, min-sdk unknown and malformed outputs; no external requests. Paths and return dataclasses are stable.

`service.py` owns ToolkitError(Exception), frozen ToolConfig(adb_path:str,aapt_path:str='',apksigner_jar:str='',java_path:str=''), frozen Plan(title:str, serial:str, details:tuple[str,...], warnings:tuple[str,...], action:str, device:DeviceInfo, apks:tuple[ApkInfo,...]=(), package:str='', old_value:str|None=None), Toolkit(config,state_dir:Path|None=None). Methods devices(), device_info(serial), packages(serial,disabled_only=False), plan_google_play(serial,paths), plan_ads(serial,restore=False), plan_package(serial,package,enable=False), plan_reboot(serial), execute(plan,confirmed=False,log=print)->list[str]. execute returns factual step results, raises descriptive errors on partial failure, serializes mutations. OPTIONAL_APPS dictionary package->label exported. DemoToolkit implements same public API without external commands and clearly fake data; UI must indicate demo.

`gui.py`: main(demo=False)->None, App(root,toolkit=None,demo=False), only uses service public API, no hardware commands itself. Connection tool paths create Toolkit. Headless import must succeed. Demo mode safe for screenshots/tests. Root supplies service and demo implementation.

### Task 1: ADB boundary (agent)
Files adb.py, tests/test_adb.py. Write failing behavior tests, run, implement, run. Cover shell metacharacters, serial option injection, multiple devices, unauthorized/offline, SDK/user unknown, install rc0 Failure, timeouts, exact args/env, safe paths. Report test evidence and constraints; do not commit shared repository.

### Task 2: APK verification (agent)
Files apk.py, tests/test_apk.py. Test then implement cryptographic-tool invocation, parsing, malformed ZIP/output, all signer pins, APK ordering/minsdk/ABIs, duplicate/wrong packages/splits. Bound ZIP/metadata resource handling, no extraction of untrusted paths. Test failures before production code. Report evidence; no shared git commits.

### Task 3: service and CLI (root)
Files service.py, cli.py, __init__.py, __main__.py, demo.py, tests/test_service.py, tests/test_cli.py. Test confirmation, identity mismatch, staged file changes, partial failure reporting, original ad snapshot retained and correct restore, safe allowlist, non-Amazon/user refusal, concurrent operations, missing tools and help. Implement fail-closed plans, atomic private undo state and readback checks. CLI has devices/info/play/ads/apps/reboot and GUI default.

### Task 4: desktop UI (agent)
Files gui.py, tests/test_gui.py. Use service interface above and optional_apps list. Real UI with useful setup, error handling, previews and confirmations, background workers with main-thread UI updates. Safe demo. Tests for imported module and relevant controller behavior, GUI smoke when display available. No service/CLI changes.

### Task 5: review, documentation and delivery (root + independent reviewer)
README.md, SECURITY.md, LICENSE, docs/REA-NOTES.md, docs/TESTING.md, launchers, pyproject.toml, scripts/package_release.py. Document exact dependencies and free-ad limitations. Independent review of each component and integrated design; fix Important/Critical findings. Run entire unittest suite, CLI/GUI smoke, lint/compile, verify source archive contains no binaries/APKs/secrets, create deterministic ZIP and checksum. Leave runnable project on feature branch without external publication.
